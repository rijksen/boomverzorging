RIJKSEN BOOMVERZORGING - LOKALE ASSETS

De map assets/ bevat de lokale foto's en documenten zodra download-assets.ps1 is uitgevoerd.

Omdat de ChatGPT-werkruimte de bestanden van de externe website niet rechtstreeks als binaire bestanden kan overnemen,
bevat deze downloadset een PowerShell-script dat de originele bestanden van rijksenboomverzorging.nl naar assets/ downloadt.

Gebruik:
1. Pak de ZIP uit.
2. Open PowerShell in deze map.
3. Voer uit:
   .\download-assets.ps1
4. Open daarna index.html.

Alle verwijzingen in index.html zijn lokaal (assets/...). Er is geen JavaScript nodig.
